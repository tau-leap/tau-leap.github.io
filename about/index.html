About

Small, lightweight tools that run on your machine and are safe to use.

軽量で安全なツールをつくっています。

Who

TauLeap is a personal project. It builds small, fast tools for developers and data engineers. Right now that means desktop apps and Chrome extensions.

TauLeap は個人プロジェクトです。
開発者やデータエンジニア向けに、小さくて速いツールをつくっています。
いまはデスクトップアプリと Chrome 拡張が中心です。

Why

TauLeap exists to build the tools I wanted.
After moving from Windows to Mac, small daily frictions piled up.
Window switching. English labels on GitHub. A pinned tab wandering off its domain.
I care about keeping tools lightweight, not sending data elsewhere, and building tools people can use with peace of mind.

自分が欲しいツールを作るために TauLeap をはじめました。
Windows から Mac に移ったあと、毎日の小さな引っかかりが増えました。
ウィンドウの切り替え。GitHub の英語ラベル。固定タブが別ドメインへ移ること。
軽量なツールであること、データを外部に送信しないこと、安心して使ってもらえるツールを作ることを、大切にしています。
