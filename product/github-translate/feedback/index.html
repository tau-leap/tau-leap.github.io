Feedback goes to GitHub Issues on the public repository.

フィードバックは公開リポジトリの GitHub Issues へどうぞ。

Open an issue Repository

What to report

Pick a template so maintainers can act on it quickly.

テンプレートを選ぶと、対応しやすくなります。

  • Untranslated label 未訳の報告
  • Translation fix 訳の修正提案
  • Bug report 不具合の報告

From the extension

In the popup, 未訳を報告 and 訳の修正を提案 open the same Issue forms with the current page URL and selected text filled in.

拡張のポップアップから「未訳を報告」「訳の修正を提案」を押すと、表示中の URL と選択テキストが入った状態で同じ Issue 作成画面が開きます。
