TauBar と代替アプリ：Mac のウィンドウ単位タスクバー

TauBar は macOS 26（Tahoe）以降・Apple Silicon のみ対応です。お使いの Mac が当てはまらない場合は、下の代替アプリをご覧ください。

TauBar は、Mac の画面下にウィンドウ単位のタスクバーを足すアプリです。このページでは、よく一緒に検討される uBar、Tungsten Edge、Winstrix、DockDoor と比べます。TauBar は私たちの製品なので、その前提で読んでください。他社の情報はすべて各社の公式ページへのリンク付きで、2026-11-12 に確認しました。価格や版は変わることがあるため、購入前にリンク先も確認してください。

TauBar が向かない人

  • Intel Mac や macOS 15 以前の Mac を使っている人。 TauBar は動きません。Tungsten Edge（macOS 12 以降、Intel と Apple silicon）、Winstrix（macOS 14 以降、Universal）、DockDoor（macOS 13 以降、Apple silicon と Intel）を検討してください。なお、現行の uBar 5 も TauBar と同じく macOS 26 以降・Apple Silicon のみです。
  • オープンソースがいい人。 TauBar はソース非公開です。Tungsten Edge と DockDoor は GitHub で GPL-3.0 として公開されています。
  • Dock はそのままで、ウィンドウのプレビューだけ欲しい人。 それなら無料の DockDoor が合っています。
  • Mac 全体を Windows のように動かしたい人。 ショートカット、スクロール、ウィンドウのスナップ、クリップボード履歴まで変えたいなら Winstrix です。TauBar はタスクバーを足すだけで、ウィンドウのタイル配置もしません。
  • 細かく設定したい人。 uBar は長年磨かれてきたアプリで、Dock 型の表示、複数段、画面のどの端にも置ける配置、テーマ、法人ライセンスがあります。

TauBar が向く人

Dock はアプリごとにまとめて表示します。TauBar は、開いているウィンドウを一つずつ、タイトル付きで画面下のバーに並べます。Chrome のプロファイルを3つ開いていても、Finder のウィンドウが何枚あっても、目的のウィンドウを直接クリックできます。Chrome のプロファイルも表示されます。

無料プランには次の機能も含まれます。

  • アプリのピン留め
  • アプリの起動と検索ができるスタートボタン
  • 時計と月カレンダー
  • マルチディスプレイ
  • 自動で隠す

Dock と併用できます。アカウントは不要で、利用状況の送信もありません。

他のアプリのほうが優れている点

  • uBar は最も成熟していて、設定の幅も最大です。タスクバー型と Dock 型を選べ、画面のどの端にも置けて、最大5段まで広げられます。モニターごとのバーやテーマもあり、法人・企業向けのライセンスもあります。
  • Tungsten Edge はベータ中は無料のオープンソースで、macOS 12 以降の Intel と Apple silicon で動きます。画面収録の権限が要らず、brew install --cask tungsten-edge で入れられます。
  • Winstrix は買い切り $14.99 で、TauBar の買い切り（$19.99）より安く買えます。ショートカット、Alt+Tab、ウィンドウのスナップ、クリップボード履歴、Windows 風のスクロールまで揃っていて、Windows から移ってきた人にはずっと多くのことをしてくれます。
  • DockDoor は無料のオープンソースで、有料の壁もありません。標準の Dock をそのまま使えます。ホバーでのプレビューとウィンドウ切り替えで足りるなら、タスクバー自体が要らないかもしれません。

TauBar が合う場面

  • macOS 26 以降・Apple Silicon の Mac で、ウィンドウをタイトル付きで画面下に並べたいとき。
  • 試用期間のあとも、タスクバーの基本機能を無料で使い続けたいとき。Pro は任意で、月額・年額・買い切り（$19.99）から選べます。
  • スタートボタン、カレンダー付きの時計、ピン留めしたアプリ、Chrome のプロファイルを一つのバーにまとめたいとき。
  • 権限を気にするとき。TauBar はアカウント不要で、利用状況を送信しません。アクセシビリティはウィンドウの識別とフォーカスにだけ使います。画面収録は、プレビューのサムネイルをオンにしたときだけ必要です。

uBar の代わりになるアプリ

uBar 5 は macOS 26 以降・Apple Silicon が必要になりました。uBar の代わりを探しているなら、状況別にこう選べます。

  • Intel Mac や古い macOS を使っている： Tungsten Edge（macOS 12 以降）か Winstrix（macOS 14 以降）。今の Dock にプレビューが付けば十分なら DockDoor（macOS 13 以降）。
  • macOS 26 以降・Apple Silicon で、無料の基本機能か安い買い切りが欲しい： TauBar（買い切り $19.99、試用後も基本機能は無料）か Winstrix（$14.99）。
  • オープンソースがいい： Tungsten Edge か DockDoor。

よくある質問

Intel Mac や macOS 15 でも動きますか？

動きません。TauBar は macOS 26（Tahoe）以降の Apple Silicon 搭載 Mac が必要です。Intel Mac や古い macOS をお使いなら、Tungsten Edge（macOS 12 以降）、DockDoor（macOS 13 以降）、Winstrix（macOS 14 以降）をご検討ください。

無料で使えますか？

10日間はすべての機能を無料で使えます。その後も、タスクバーの基本機能は無料のままです。ウィンドウ切り替え、ピン留め、スタートメニュー、時計とカレンダー、マルチディスプレイが含まれます。Pro は月 $0.99・年 $9.99・買い切り $19.99 で、2台まで使えます。

Dock の代わりになりますか？

どちらかを選ぶ必要はありません。Dock との併用をおすすめしています。Dock を左右に寄せて、タスクバーを主役にする使い方もできます。

オープンソースですか？

いいえ。オープンソースを重視するなら、GPL-3.0 の Tungsten Edge か DockDoor をご検討ください。

DockDoor とは何が違いますか？

DockDoor は、標準の Dock にウィンドウのプレビューと ⌥Tab の切り替えを足すアプリです。TauBar は画面下に別のバーを置き、ウィンドウを一つずつタイトル付きの項目として並べます。
