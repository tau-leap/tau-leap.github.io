English

1. Summary

TauDiff is a text comparison tool that runs entirely on your own computer. It has no account system, no cloud sync, no analytics and no telemetry, and it makes no network requests. The files you compare and edit never leave your computer, and TauLeap receives nothing from the application.

2. Information we collect

TauLeap collects no personal information through the TauDiff application. There is no sign-up, no login, no usage tracking, no crash reporting service and no advertising identifier. No third-party analytics SDK is embedded.

If you contact us by email, we receive the information you choose to include in that message — typically your email address and the contents of your enquiry. We use it only to respond to you.

3. Data stored on your device

TauDiff keeps the following on your computer, under your own user account:

  • The files you compare. They are read from, and saved back to, the locations you choose. TauDiff does not copy them anywhere else.
  • Interface preferences. Settings such as font size are stored locally so they persist between launches.

None of this is transmitted to TauLeap. Please note that files in your home directory may be included in backups you have configured yourself, such as Time Machine, File History or a cloud backup service.

4. Network communication

TauDiff performs local file input and output and renders its interface locally. It does not contact TauLeap or any other server, and it does not send your file contents, file names or file paths anywhere.

5. Third parties

We do not sell, rent or share personal information. TauDiff integrates no advertising networks, no data brokers and no third-party services that receive your data.

6. This website

This page is published on GitHub Pages, operated by GitHub, Inc. GitHub may log standard request information such as IP address for security and operational purposes. Web fonts on this page are served by Google Fonts. We run no analytics, no cookies and no tracking pixels on this site.

7. Security

Because your files stay on your own machine, their security depends primarily on the security of that machine. We recommend using full-disk encryption and keeping your operating system up to date.

8. Children

TauDiff is a general-purpose tool and is not directed at children. We do not knowingly collect information from children.

9. Your rights

Since we hold no personal data about TauDiff users, there is normally nothing for us to disclose, correct or delete. If you have emailed us and would like that correspondence removed, write to email and we will delete it.

10. Changes to this policy

If we change how TauDiff handles data, we will update this page and revise the "Last updated" date above. Material changes will be reflected here before or at the time they take effect.

日本語

1. 概要

TauDiff は、お使いのコンピュータ内で完結して動作するテキスト比較ツールです。アカウント機能、クラウド同期、解析、テレメトリのいずれも備えておらず、ネットワーク通信も行いません。比較・編集したファイルがコンピュータの外に出ることはなく、TauLeap がアプリケーションから情報を受け取ることもありません。

2. 収集する情報

TauLeap は、TauDiff アプリケーションを通じて個人情報を一切収集しません。会員登録、ログイン、利用状況の追跡、クラッシュレポート送信、広告識別子のいずれもありません。第三者の解析 SDK も組み込んでいません。

メールでお問い合わせいただいた場合は、そのメールに含まれる情報（通常はメールアドレスとお問い合わせ内容）を受け取ります。これは返信のためだけに利用します。

3. 端末内に保存されるデータ

TauDiff は、次の情報をお客様のコンピュータのユーザーアカウント配下に保持します。

  • 比較するファイル — お客様が指定した場所から読み込まれ、指定した場所へ保存されます。TauDiff が他の場所へ複製することはありません。
  • 画面設定 — フォントサイズなどの設定は、次回起動時に引き継げるようローカルに保存されます。

これらが TauLeap に送信されることはありません。なお、ホームディレクトリ配下のファイルは、Time Machine、ファイル履歴、クラウドバックアップなど、お客様ご自身が設定したバックアップの対象に含まれる場合があります。

4. ネットワーク通信

TauDiff はローカルのファイル入出力と画面描画のみを行います。TauLeap を含むいかなるサーバーとも通信せず、ファイルの内容・ファイル名・ファイルパスを外部へ送信することもありません。

5. 第三者提供

当社は個人情報の販売・貸与・共有を行いません。TauDiff には、広告ネットワーク、データブローカー、およびお客様のデータを受け取る第三者サービスのいずれも組み込まれていません。

6. 本ウェブサイトについて

本ページは GitHub, Inc. が運営する GitHub Pages 上で公開されています。GitHub は、セキュリティおよび運用上の目的で IP アドレスなど標準的なリクエスト情報を記録する場合があります。本ページのウェブフォントは Google Fonts から配信されます。本サイトでは解析ツール、Cookie、トラッキングピクセルのいずれも使用していません。

7. セキュリティ

ファイルはお客様の端末内に保持されるため、その安全性は主に端末自体の安全性に依存します。ディスク全体の暗号化と、OS を最新の状態に保つことを推奨します。

8. 子どもの利用について

TauDiff は汎用ツールであり、子どもを対象としたものではありません。当社が子どもから情報を意図的に収集することはありません。

9. お客様の権利

当社は TauDiff の利用者に関する個人データを保有していないため、通常、開示・訂正・削除の対象となる情報はありません。メールでご連絡いただいた履歴の削除をご希望の場合は、email までご連絡ください。削除いたします。

10. 本ポリシーの変更

TauDiff のデータの取り扱いを変更する場合は、本ページを更新し、上部の「Last updated」を改訂します。重要な変更については、効力発生前または発生時点で本ページに反映します。
