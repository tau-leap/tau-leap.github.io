English

1. Summary

TauDiff is a text comparison tool that runs on your own computer. It has no account system, no cloud sync, no analytics and no telemetry. The files you compare and edit never leave your computer. The only network use by the application is checking for updates (and downloading them if you choose) via GitHub Releases.

2. Information we collect

TauLeap collects no personal information through the TauDiff application. There is no sign-up, no login, no usage tracking, no crash reporting service and no advertising identifier. No third-party analytics SDK is embedded.

If you contact us by email, we receive the information you choose to include in that message — typically your email address and the contents of your enquiry. We use it only to respond to you.

3. Data stored on your device

TauDiff keeps the following on your computer, under your own user account:

  • The files you compare. They are read from, and saved back to, the locations you choose. TauDiff does not copy them anywhere else.
  • Interface preferences. Settings such as font size and whether to check for updates automatically are stored locally so they persist between launches.

None of this is transmitted to TauLeap. Please note that files in your home directory may be included in backups you have configured yourself, such as Time Machine, File History or a cloud backup service.

4. Network communication

Comparison and editing are local. TauDiff does not send your file contents, file names or file paths anywhere. Network requests occur only for updates:

  • Update checks. By default on launch, and when you choose Check for Updates from the menu, TauDiff contacts GitHub Releases (the update metadata at https://github.com/tau-leap/taudiff/releases/latest/download/latest.json). As with any network request, the servers involved may log your IP address and application version. Your files are not included.
  • Update download. If a newer version is available and you confirm, the update package is downloaded from GitHub Releases and installed locally.

Automatic update checks can be turned off by setting updates.automaticallyCheckForUpdates to false in the application's local settings file. Manual checks from the menu still contact GitHub when you use them.

5. Third parties

We do not sell or share personal information as those terms are defined under the CCPA/CPRA, and we do not rent it. We do not use personal information for cross-context behavioural advertising. TauDiff integrates no advertising networks and no data brokers. The only third party involved in network traffic from the application is GitHub, which hosts update metadata and release downloads under its own privacy policy.

6. This website

This page is published on GitHub Pages, operated by GitHub, Inc. GitHub may log standard request information such as IP address for security and operational purposes. Web fonts on this page are served by Google Fonts. We run no analytics, no cookies and no tracking pixels on this site.

7. Security

Because your files stay on your own machine, their security depends primarily on the security of that machine. We recommend using full-disk encryption and keeping your operating system up to date.

8. Children

TauDiff is a general-purpose tool and is not directed at children. We do not knowingly collect information from children.

9. Your rights

Since we hold no personal data about TauDiff users, there is normally nothing for us to disclose, correct or delete. If you have emailed us and would like that correspondence removed, write to email and we will delete it. If you are in the EEA or the United Kingdom, the rights of access, rectification, erasure, restriction, portability, objection and complaint to a supervisory authority apply to that correspondence.

10. Changes to this policy

If we change how TauDiff handles data, we will update this page and revise the "Last updated" date above. Material changes will be reflected here before or at the time they take effect.

日本語

1. 概要

TauDiff は、お使いのコンピュータ上で動作するテキスト比較ツールです。アカウント機能、クラウド同期、解析、テレメトリのいずれも備えていません。比較・編集したファイルがコンピュータの外に出ることはありません。アプリケーションによるネットワーク通信は、GitHub Releases を通じたアップデート確認（およびお客様が選択した場合のダウンロード）に限られます。

2. 収集する情報

TauLeap は、TauDiff アプリケーションを通じて個人情報を一切収集しません。会員登録、ログイン、利用状況の追跡、クラッシュレポート送信、広告識別子のいずれもありません。第三者の解析 SDK も組み込んでいません。

メールでお問い合わせいただいた場合は、そのメールに含まれる情報（通常はメールアドレスとお問い合わせ内容）を受け取ります。これは返信のためだけに利用します。

3. 端末内に保存されるデータ

TauDiff は、次の情報をお客様のコンピュータのユーザーアカウント配下に保持します。

  • 比較するファイル — お客様が指定した場所から読み込まれ、指定した場所へ保存されます。TauDiff が他の場所へ複製することはありません。
  • 画面設定 — フォントサイズや、起動時の自動アップデート確認の有無などの設定は、次回起動時に引き継げるようローカルに保存されます。

これらが TauLeap に送信されることはありません。なお、ホームディレクトリ配下のファイルは、Time Machine、ファイル履歴、クラウドバックアップなど、お客様ご自身が設定したバックアップの対象に含まれる場合があります。

4. ネットワーク通信

比較と編集はローカルで行われます。ファイルの内容・ファイル名・ファイルパスを外部へ送信することはありません。ネットワーク通信が発生するのはアップデートに関する場合のみです。

  • アップデート確認 — 既定では起動時、およびメニューから「更新を確認」を選んだときに、TauDiff は GitHub Releases（更新用メタデータ https://github.com/tau-leap/taudiff/releases/latest/download/latest.json）へアクセスします。一般的なネットワーク通信と同様に、関係するサーバーが IP アドレスやアプリのバージョンを記録する場合があります。お客様のファイルは含まれません。
  • アップデートのダウンロード — 新しいバージョンがあり、お客様がインストールを承認した場合、更新パッケージは GitHub Releases からダウンロードされ、端末内にインストールされます。

起動時の自動アップデート確認は、アプリのローカル設定ファイルで updates.automaticallyCheckForUpdates を false にすることで無効にできます。メニューからの手動確認は、実行時に引き続き GitHub へアクセスします。

5. 第三者提供

当社は、CCPA/CPRA にいう個人情報の販売・共有を行わず、貸与もしません。クロスコンテキストの行動広告にも使いません。TauDiff には広告ネットワークやデータブローカーは組み込まれていません。アプリケーションからのネットワーク通信に関与する第三者は、アップデート用メタデータとリリース配信をホストする GitHub のみであり、受領したデータは GitHub のプライバシーポリシーに従って取り扱われます。
