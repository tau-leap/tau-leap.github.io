English

1. Summary

TauPad is a text editor that runs entirely on your own computer. It has no account system, no cloud sync, no analytics and no telemetry. The files you open and edit never leave your computer, and TauLeap receives nothing from the application.

2. Information we collect

TauLeap collects no personal information through the TauPad application. There is no sign-up, no login, no usage tracking, no crash reporting service and no advertising identifier. No third-party analytics SDK is embedded.

If you contact us by email, we receive the information you choose to include in that message — typically your email address and the contents of your enquiry. We use it only to respond to you.

3. Data stored on your device

TauPad keeps the following on your computer, under your own user account:

  • Your documents. The files you open are read from, and saved to, the locations you choose. TauPad does not copy them anywhere else.
  • Settings. Editor preferences are stored in the application's settings file.
  • Session state. Information about open tabs and interface state, such as panel width, is stored locally so your workspace can be restored on the next launch.

None of this is transmitted to TauLeap. Removing the application data directory removes it. Please note that files in your home directory may be included in backups you have configured yourself, such as Time Machine, File History or a cloud backup service.

4. Network communication

TauPad does not make network requests to TauLeap and does not send your document contents, file names or file paths anywhere. The only case in which a network connection occurs is when you deliberately activate a link — for example clicking a hyperlink in the Markdown preview — which opens that address in your default web browser. From that point your browser and the destination site apply, not TauPad.

5. Third parties

We do not sell, rent or share personal information. TauPad integrates no advertising networks, no data brokers and no third-party services that receive your data.

6. This website

This page is published on GitHub Pages, operated by GitHub, Inc. GitHub may log standard request information such as IP address for security and operational purposes. Web fonts on this page are served by Google Fonts. We run no analytics, no cookies and no tracking pixels on this site.

7. Security

Because your documents stay on your own machine, their security depends primarily on the security of that machine. We recommend using full-disk encryption and keeping your operating system up to date.

8. Children

TauPad is a general-purpose tool and is not directed at children. We do not knowingly collect information from children.

9. Your rights

Since we hold no personal data about TauPad users, there is normally nothing for us to disclose, correct or delete. If you have emailed us and would like that correspondence removed, write to email and we will delete it.

10. Changes to this policy

If we change how TauPad handles data, we will update this page and revise the "Last updated" date above. Material changes will be reflected here before or at the time they take effect.

日本語

1. 概要

TauPad は、お使いのコンピュータ内で完結して動作するテキストエディタです。アカウント機能、クラウド同期、解析、テレメトリのいずれも備えていません。開いたファイルや編集内容がコンピュータの外に出ることはなく、TauLeap がアプリケーションから情報を受け取ることもありません。

2. 収集する情報

TauLeap は、TauPad アプリケーションを通じて個人情報を一切収集しません。会員登録、ログイン、利用状況の追跡、クラッシュレポート送信、広告識別子のいずれもありません。第三者の解析 SDK も組み込んでいません。

メールでお問い合わせいただいた場合は、そのメールに含まれる情報（通常はメールアドレスとお問い合わせ内容）を受け取ります。これは返信のためだけに利用します。

3. 端末内に保存されるデータ

TauPad は、次の情報をお客様のコンピュータのユーザーアカウント配下に保存します。

  • ドキュメント — 開いたファイルは、お客様が指定した場所から読み込まれ、指定した場所に保存されます。TauPad が他の場所へ複製することはありません。
  • 設定 — エディタの各種設定は、アプリケーションの設定ファイルに保存されます。
  • セッション情報 — 次回起動時に作業状態を復元できるよう、開いているタブやパネル幅などの画面状態がローカルに保存されます。

これらが TauLeap に送信されることはありません。アプリケーションのデータディレクトリを削除すれば、データも削除されます。なお、ホームディレクトリ配下のファイルは、Time Machine、ファイル履歴、クラウドバックアップなど、お客様ご自身が設定したバックアップの対象に含まれる場合があります。

4. ネットワーク通信

TauPad が TauLeap に対してネットワーク通信を行うことはなく、ドキュメントの内容・ファイル名・ファイルパスを外部へ送信することもありません。ネットワーク接続が発生するのは、お客様が意図的にリンクを操作した場合（Markdown プレビュー内のリンクをクリックした場合など）に限られ、その際は既定のウェブブラウザで当該アドレスが開かれます。それ以降は TauPad ではなく、お客様のブラウザと接続先サイトの取り扱いが適用されます。

5. 第三者提供

当社は個人情報の販売・貸与・共有を行いません。TauPad には、広告ネットワーク、データブローカー、およびお客様のデータを受け取る第三者サービスのいずれも組み込まれていません。

6. 本ウェブサイトについて

本ページは GitHub, Inc. が運営する GitHub Pages 上で公開されています。GitHub は、セキュリティおよび運用上の目的で IP アドレスなど標準的なリクエスト情報を記録する場合があります。本ページのウェブフォントは Google Fonts から配信されます。本サイトでは解析ツール、Cookie、トラッキングピクセルのいずれも使用していません。

7. セキュリティ

ドキュメントはお客様の端末内に保持されるため、その安全性は主に端末自体の安全性に依存します。ディスク全体の暗号化と、OS を最新の状態に保つことを推奨します。

8. 子どもの利用について

TauPad は汎用ツールであり、子どもを対象としたものではありません。当社が子どもから情報を意図的に収集することはありません。

9. お客様の権利

当社は TauPad の利用者に関する個人データを保有していないため、通常、開示・訂正・削除の対象となる情報はありません。メールでご連絡いただいた履歴の削除をご希望の場合は、email までご連絡ください。削除いたします。

10. 本ポリシーの変更

TauPad のデータの取り扱いを変更する場合は、本ページを更新し、上部の「Last updated」を改訂します。重要な変更については、効力発生前または発生時点で本ページに反映します。
